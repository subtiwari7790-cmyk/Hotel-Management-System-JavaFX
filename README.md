# Hotel Management System     
      
A desktop Hotel Management System developed using Java, JavaFX, and Maven.  
Slight modifications in Hotel Management System project.       

## Features  
   
- Add Rooms
- Book Rooms 
- Customer Management
- Search Bookings
- Check In / Check Out
- File Handling

## Technologies

- Java
- JavaFX
- Maven
